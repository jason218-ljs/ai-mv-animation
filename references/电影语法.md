# 电影语法

运镜库解决「镜头怎么动」，这份文件解决「为什么这么切」。前者是技法，后者是语法——语法错了，技法再漂亮也是散的。

---

## 一、景别：五个层级，五种职能

| 景别 | 取景 | 职能 | MV 里的用法 |
|---|---|---|---|
| 大远景 / 远景（EWS/WS） | 环境为主，人极小 | 交代环境、渲染气氛、写「渺小」 | 开篇定调、结尾拉远 |
| 全景（FS） | 全身 + 周边环境 | 展示主体与空间的关系 | 双人并肩走、隔海相望 |
| 中景（MS） | 膝以上 | 记录动作、交代关系 | 蹲下捧沙、并肩走路 |
| 近景（CU） | 胸以上 | 传递情绪、看神态 | 说话、微表情 |
| 特写 / 大特写（ECU） | 肩以上 / 局部 | 放大细节、制造压迫 | 瞳孔里的火星、指尖穿碎片 |

### 「剥洋葱」式展开

远景划定空间坐标 → 全景交代关系 → 中景聚焦动作 → 近景捕捉细节 → 特写放大情绪。

这是**默认的推进顺序**，也是观众理解一个场景的自然路径。

MV 的特殊之处：它常常**反着用**——先给特写（一滴水、一片碎片），再拉到远景（原来是一片海）。这是「揭示」，比顺推更有冲击力。

### 两条硬规则

**规则 1：两极景别不直接衔接。**
大特写直接接大远景，观众会觉得突兀、跳。中间要有一个过渡景别，或者用转场（如瞳孔扩张吞画面）来桥接。

**规则 2：同主体相邻镜头的机位夹角 ≥ 30°。**
这就是**30 度规则**。夹角小于 30° 的两个镜头接在一起，会产生「跳接感」——观众觉得画面「抖了一下」，像是同一个镜头被剪掉了一段。

对话场景尤其明显：正反打如果只差 15°，人物视线方向会自相矛盾。

AI 生成时这条特别容易破，因为你每镜是独立生成的，很容易给出「几乎一样但略有差异」的两个机位。**做法**：在分镜表里标注每镜的机位角度（如「正面 0°」「侧面 90°」「过肩 45°」），相邻两镜的差值必须 ≥ 30°。

## 二、焦段：空间关系的操纵杆

焦段比景别更隐蔽，但对情绪的影响更大。景别决定「看到多少」，焦段决定「空间长什么样」。

| 焦段 | 空间效果 | 人物效果 | 情绪 |
|---|---|---|---|
| 广角（18–28mm） | 空间被拉开、透视夸张 | 人物变形、边缘拉伸 | 压迫、不安、主观、环境的吞噬感 |
| 标准（35–50mm） | 接近人眼 | 自然 | 客观、克制、日常 |
| 长焦（85–200mm） | 空间被压缩、前后景贴近 | 人物被「抠」出来 | 亲密、隔离、凝视、命运的贴近 |

两个关键用法：

**长焦压缩 = 亲密或窒息。** 两个人明明隔很远，长焦一拍就像贴在一起；反过来，明明并肩，长焦也能让他们显得各自孤立。MV 里表现「时差」时极好用——同一画面里两个人被压得很近，但眼神没有交集。

**广角 = 主观与渺小。** 少女主观视角看海，用广角，海会显得无边，人显得极小。这和「广袤」这个情绪直接对应。

写法：在提示词里给具体焦段，不要写「电影感」。

```
✗ 电影感镜头
✓ 35mm 焦段，f/4 光圈，浅景深
✓ 85mm 长焦压缩，背景与人物贴合
✓ 24mm 广角，边缘轻微拉伸
```

## 三、机位角度：谁在高处

| 角度 | 效果 | 用途 |
|---|---|---|
| 平视 | 平等、客观 | 默认 |
| 仰视 | 主体被抬高、有权威或敬畏感 | 少年登场、烟花升起 |
| 俯视 | 主体被压低、渺小、被命运注视 | 开篇大远景、失败、被抛弃 |
| 荷兰角（倾斜） | 失衡、不安、心理错位 | 时差、崩塌——**全片最多 1 次** |

俯视是 MV 开篇的常用解：人在画面里只占 1/12，头顶是压下来的云。观众第一眼就接收到了「渺小」。

## 四、视线匹配：看向画外，就得给答案

**规则**：人物看向画外，下一个镜头必须给出他看的东西，并且方向要对。

她向左上方看 → 下一镜的物体应该在画面右侧或正前方（因为她的视线穿过画面）。

破了这条，观众会觉得「她看的东西不对」，但说不出为什么。

**进阶**：视线匹配可以跨越多镜。她看向画外 → 中间插两个别的镜头 → 最后才给出她看的东西。距离越远，揭示的力量越大。

## 五、库里肖夫效应：MV 里最省钱的一招

库里肖夫做过一个实验：同一个男人的中性表情，分别接一碗汤、一具棺材、一个女孩，观众就分别读出了「饥饿」「悲痛」「欲望」。

**结论：情绪不在表演里，在剪辑里。**

这对 MV 的意义极大——因为 AI 生成「细腻的表演」是最难的，但生成「一个安静的中性表情」很容易。

所以最有效的分镜策略是：

> **先拍中性反应镜头，再决定接什么。**

同一个「少女安静垂眼」的镜头：

- 接**翻涌的大海** → 辽阔、向往
- 接**空玻璃罐** → 失落
- 接**少年远去的背影** → 告别
- 接**熄灭的烟花** → 幻灭

一个镜头，四种含义。这就是为什么原案例里少女「眼神安静、少表情」——不是省事，是**留白给剪辑**。

**实操建议**：全片专门留 1–2 个「中性反应镜头」，在剪辑时反复试接不同内容，选最有味道的那个。这类镜头要拍得足够「空」——表情太满反而锁死了含义。

## 六、匹配剪辑：四种匹配方式

匹配剪辑是「两个不同时空的镜头，因为某个共同点而被缝在一起」。观众意识不到切了，只觉得顺。

| 类型 | 匹配什么 | 例 |
|---|---|---|
| 动作匹配 | 同一个动作跨镜延续 | 合掌 → 碎片落下 → 下一镜碎片落水 |
| 形状匹配 | 两个物体的轮廓相似 | 圆形空洞 → 瞳孔 |
| 色彩匹配 | 两个镜头的同一个颜色 | 罐中琥珀光 → 烟花金色 |
| 声音匹配 | 相似的声音或节奏 | 水花声 → 鼓点 |

**形状匹配和色彩匹配是最容易被忽略、也最出效果的两种。** 因为它们不需要动作连续，只需要视觉上「像」。

设计方法：分镜时列出每一镜的「主要形状」和「主要颜色」，找相邻两镜的共同点。找不到，就调整其中一镜的构图或色板。

## 七、蒙太奇：两种，别混用

**叙事蒙太奇**（推进情节）

- 连续：A→B→C，时间顺序
- 平行：两条线交替，暗示同时发生
- 交叉：两条线加速交替，制造紧张
- 复现：同一个画面反复出现，累积含义

**表现蒙太奇**（表达情绪）

- 对比：富与贫、暖与冷、满与空
- 隐喻：用物象代替抽象（黑碎片沉海 = 淘汰不开心）
- 心理：用画面外化内心（碎片聚成背影又碎开）

MV 几乎全部是**表现蒙太奇**。这也解释了为什么意象映射表那么重要——表现蒙太奇靠的就是物象与含义的对应关系。

如果一支 MV 看完「很美但不知道在讲什么」，通常是叙事蒙太奇和表现蒙太奇混着用了：一会儿在推进情节，一会儿在抒情，观众跟不上。

**选一种，贯彻到底。** 抒情歌选表现蒙太奇。

## 八、节奏编排：慢—快—慢

不要每镜都在动。运镜节奏要有起伏。

| 段落功能 | 运镜 | 景别 |
|---|---|---|
| 开篇建立空间 | 慢摇 / 拉镜 | 远景 |
| 对话与情绪 | 轻推 / 固定机位 | 近景 |
| 情绪高点 | 快速推镜 / 甩镜 | 特写 |
| 反转或揭示 | 拉镜 | 从特写拉到全景 |
| 转场 | 甩镜 / 变焦模糊 | — |
| 收尾 | 后退拉远 / 静止 | 远景 |

「慢—快—慢」是最稳的三段式。全片只有一个「快」的峰值，位置在情绪曲线的最高点。

## 九、分镜时的六个问题

每设计一镜，按顺序问：

1. **这一镜的职能是什么？**（交代 / 推进 / 抒情 / 揭示）答不出就是废镜。
2. **景别选对了吗？** 要情绪还是信息？情绪走近景，信息走远景。
3. **和上一镜的机位夹角 ≥ 30° 吗？** 不够就改机位。
4. **景别跨度会不会太大？** 大特写接大远景要加过渡。
5. **人物看向画外了吗？** 看了，下一镜必须给答案。
6. **这一镜能不能做「中性反应镜头」？** 能，就拍得空一点，留给剪辑。

六个问题过完，这一镜基本不会错。
