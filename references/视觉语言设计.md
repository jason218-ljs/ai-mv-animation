# 视觉语言设计

色板、明度、光线、世界观、意象映射、情绪曲线——这六样决定了片子「像不像一个人拍的」，也决定了模型有没有稳定的坐标可依。

本篇前三节来自动画工业的色彩脚本（color script）方法（皮克斯提出，用于在正式制作前把整片情绪画成一条可读的色彩线）。它的核心是：**先解决可读性，再解决美感。** 这一点和 AI 生成尤其契合——因为模型最擅长的就是「好看」，最不擅长的就是「让人看见该看的东西」。

---

## 一、先写镜头目的，再画颜色

不要从「这里应该是蓝色」开始，从「这一镜观众该做什么」开始。

| ✗ 错的起点 | ✓ 对的起点 |
|---|---|
| 这一段是忧伤的蓝色 | 这一镜要让观众发现沙里混着黑碎片 |
| 这里要暖一点 | 这一镜要让观众注意到他的手在抖 |
| 高潮用金色 | 这一镜要让观众先看到罐子，再看到她的脸 |

**用一句动词短语写镜头目的，不要用形容词。** 形容词无法被检查，动词可以。

写完目的，颜色才有依据：要让观众发现碎片，碎片的明度必须高于沙；要让观众注意手，手的边缘必须与背景分离。

这一步在总纲阶段做，不是分镜阶段。做完之后，色板才有「为什么」。

---

## 二、明度先行：先压成三档，再谈颜色

这是整个方法里最容易被跳过、也最能救命的一步。

**做法**：把每一镜压成三档明暗（深 / 中 / 浅），只回答一个问题——**观众第一眼看到的是什么？**

如果压成黑白之后焦点散了，配色再漂亮也没用。因为人眼在读懂颜色之前，先读懂明暗。

### 三档怎么分

| 档 | 面积占比 | 承担什么 |
|---|---|---|
| 最深 | 40–60% | 空间、压暗的边缘、画面的「底」 |
| 中间 | 30–40% | 主体所在层 |
| 最浅 | 5–15% | **焦点**——唯一允许最亮的地方 |

关键约束：**最浅的那一档，一镜只给一个东西。**

给了两个（比如她的脸和罐子都很亮），观众的眼睛就不知道往哪看。

### 三个版本的对照练习

同一构图，画三个版本：

- A：人物最亮 → 观众看她
- B：道具最亮 → 观众看罐子
- C：背景最亮 → 观众感到空间很大、人很小

然后为每个版本写一句预期：「看见她的犹豫」/「注意到罐子」/「感到门外空旷」。

选哪个，取决于第一节写的镜头目的。

### 落进 AI 提示词怎么写

明度关系是可以用语言指定的：

```
画面明度三档：天空与湿沙为最深（约 50% 面积），人物为中调，
只有罐中光和她的睫毛高光是最亮的（不足 10% 面积）。焦点在罐子上。
```

这比写「光线柔和、氛围感强」有效得多。

## 三、有限配色：给每种颜色一个任务

不要「这一镜用蓝绿金」。要给每个颜色分配角色，并且**全片角色不变**。

| 角色 | 职责 | 面积 | 全片是否固定 |
|---|---|---|---|
| **背景色** | 负责空间。决定「这是哪里」 | 最大 | 固定，只随段落变色温 |
| **主体色** | 负责识别。决定「这是谁」 | 中 | **全片绝对固定** |
| **强调色** | 负责指引。只在需要的地方出现 | 最小 | 固定，只在关键处出现 |

### 三色角色制在 MV 里的落地

以海边小城为例：

- 背景色：冷灰蓝 → 青蓝 → 暖青绿 → 品红夜色（随段落走）
- 主体色：**米白毛衣 + 深藏青裙 + 黑发**（全片不变，这是识别她的唯一依据）
- 强调色：**琥珀**（只在「被照亮」的时刻出现：少年的肩线、罐中光、手腕细线、烟花）

**强调色的纪律**：一镜最多出现一次，且面积不超过 10%。琥珀用得越省，出现时越有力量。如果每一镜都有琥珀，它就不再是「光」，只是「颜色」。

### 为什么这套比 HEX 列表更好用

HEX 列表告诉你「用什么颜色」，三色角色制告诉你「这个颜色在这一镜干什么活」。

前者是素材，后者是分工。**分镜时你需要的是分工**——因为你要判断的是「这一镜的琥珀该不该出现」，而不是「这一镜的蓝色是 #2E3B4E 还是 #3A4A60」。

两者配合使用：角色制管逻辑，HEX 管精度。

## 四、色板时间轴

### 为什么必须分段时间码

生成模型没有叙事记忆。它不知道「这一镜是高潮」还是「这一镜是告别」，它只知道这一帧该是什么颜色。所以颜色必须由你按时间点直接指定，不能指望模型从上下文推断。

写成形容词（「整体偏冷，高潮转暖」）的结果是：每个片段各自理解一次「偏冷」，最后拼起来冷暖乱跳。

### 骨架：三段或五段

抒情向 MV 最稳的骨架是 **冷 → 暖 → 冷**，中间插一个「满」的高点：

| 段落 | 功能 | 典型色 | 饱和度 | 颗粒 |
|---|---|---|---|---|
| 起 | 渺小、未获得 | 冷灰蓝，低饱和 | 低 | 多 |
| 转 | 被照亮 | 青蓝 + 第一束暖色 | 中 | 减 |
| 承 | 温热日常 | 暖青绿 + 琥珀 | 中高 | 少 |
| 满 | 盛放（夜/高潮） | 品红 + 金，高光允许溢出 | 高 | 最少 |
| 收 | 失去、告别 | 回到冷蓝，但边缘留一缕暖 | 中低 | 增 |

### 每段必须写全的七个字段

```
时间码区间：0:00–0:08
主色：#2E3B4E（冷灰蓝）
辅色：#4A5A70
明度关系：最深占 55%（天空+湿沙），最亮不足 8%（水面反光）
颜色角色：背景=冷灰蓝 / 主体=米白+藏青 / 强调=无（本段不出现琥珀）
饱和度：低
颗粒：明显，纸张颗粒
画幅占比：天空占 70%（构图约束也是色板的一部分）
越界许可：无 / 或「高光允许轻微溢出」
```

**画幅占比也要写进色板**——因为「天空占 70%」这种构图约束，直接决定了这一段的色块面积配比，是色板能不能落地的关键。

### 方向锁

每份色板后面加一句硬性声明：

> 色板走向必须遵守，不许反向。

「不许反向」这四个字能挡住模型自作聪明的「情绪反转」。如果片子里确实有反向（比如回闪），要单独标注例外并给时间码。

### 收尾的「余温」技巧

最后一镜回到冷调时，不要彻底变灰：

> 0:37–0:47：回到冷蓝，但画面边缘始终保留一缕琥珀余温，不许彻底变灰。

冷到底 = 情绪归零 = 观众觉得白看了。留一缕暖色，情绪才是「失去」而不是「没发生过」。这是全片最容易漏、也最影响回味的一笔。

## 五、冷暖转场：让变化发生在动作里

色板从冷到暖，如果是在切点处「啪」地换掉，观众会觉得「怎么突然变天了」。

**规则：温度变化必须有空间依据，并且发生在动作里。**

### 桥接镜头

在冷段和暖段之间插一个镜头，让颜色**从道具扩散到人，再扩散到空间**。

例：

1. 冷段最后一镜：灰蓝的房间里，桌上有一只杏黄色的信封（强调色先出现在道具上）
2. 桥接镜：手伸过去，杏黄从信封扩散到手背（强调色进入人物）
3. 暖段第一镜：暖光已经爬到她脸上，冷灰退到背景（强调色占据主体）

观众看到的是「光走过来了」，不是「换了个滤镜」。

### 三个具体的桥接载体

| 载体 | 做法 |
|---|---|
| 门缝 / 窗缝 | 暖光先只从一条缝里进来，再扩大 |
| 走廊 / 通道 | 人物走向光源，暖色面积随距离增大 |
| 一盏灯 / 一束火 | 点亮的那一刻，暖色从光源向外扩散 |

原案例 S07 就是这个逻辑：袖口在雾玻璃上抹出一道弧，玻璃外的灰云被「擦开」，露出一条金色的缝——**暖色是从她自己的动作里长出来的**，不是凭空出现的。

## 六、人物可读性：换了灯光，还是同一个人

跨镜一致性最容易被忽略的一面：不是「脸一样」，而是「在远景和暗部里还认得出」。

### 两底三状态测试

生成角色参考图之后，做这个测试：

1. 准备两个底板：**浅墙** 和 **深墙**
2. 把同一个角色放进去，各测三种状态：**门外（远景）**、**门口（中景）**、**灯下（近景）**
3. 得到六格，人物大小保持一致
4. 逐格检查：**头部轮廓、服装色组、关键配饰、手里的道具** 是否还能辨认

### 判断标准

把六格缩到手机屏幕大小（约 400px 宽），如果在这一尺寸下认不出是谁，说明角色锚点在远景尺度上失效了。

**失效的常见原因**：配饰太小。发卡、红绳这类东西在远景里完全消失。

**解法**：给角色一个**大尺度的识别特征**——不是发卡，而是「米白色 oversized 毛衣」这种占画面面积大的色块。远景靠色块认人，近景靠配饰认人。

这也是原案例把「米白色 oversized 粗针毛衣」写进设定的深层原因：它不只是服装，它是远景识别码。

## 七、光线设计

### 铁则：方位恒定，色温可变

光源**方位**全片不变，只允许色温按段落切换：

> 主光永远来自画面右后上方；前 24 秒为冷光，25 秒起换为暖光，37 秒后重新转冷。禁止光源跳位。

原因：影子方向是观众判断「同一空间」的潜意识依据。光源方位一跳，观众说不出哪里不对，但会觉得「换了个地方」。

### 三种光的具体写法

| 光型 | 用途 | 写法要点 |
|---|---|---|
| 逆光轮廓光 | 「被照亮」的时刻、重要人物登场 | 只打亮肩线/发缘，主体仍在暗部。写「第一束琥珀光从右后上方穿云而下，只打亮他的肩线」 |
| 体积光 | 空气感、希望感 | 必须写介质（云缝、雾、雨、烟），无介质的体积光会变成廉价光晕 |
| 环境反光 | 水面、湿沙、玻璃 | 写「湿沙如镜」，反光是这个世界观的物理基础，不是装饰 |

### 暗处也可以是安全区

不要默认「亮 = 好，暗 = 压抑」。安全感来自人物关系，不由亮度单独决定。

门外明亮但空无一人，室内偏暗但有人在等——**暗的房间可以是安全区**。这一条能救掉很多「一味压暗表示悲伤」的俗套。

## 八、世界观压缩法

一句话世界观 = **场景** + **一条异常规则** + **情感投射**

范本：

> 一座退潮后的海边小城。湿沙如镜，天空低垂得像一只倒扣的玻璃罐，沙滩上散落着会发光的玻璃碎片——每一片都是一段回忆。主角收集碎片装进玻璃罐；少年是唯一能让碎片亮起来的人。

拆开看：

- 场景：退潮后的海边小城（具体、有物理质感）
- 异常规则：沙滩上有会发光的玻璃碎片，每片是一段回忆（一条，不要两条）
- 情感投射：少年是唯一能让碎片亮起来的人（把抽象关系变成物理事实）

**只给一条异常规则。** 给三条，模型记不住，画面会乱。一条规则 + 反复使用，才有世界观的重量。

## 九、意象映射表

把每个抽象情绪钉到一个**能被拍到的物理事实**上。这张表是全片的意义骨架，也是防止「画面很美但不知道在讲什么」的解药。

| 抽象情绪 | 物理物象 | 可拍的动作 |
|---|---|---|
| 广袤 | 大海 | 抬眼，云裂开，海平线露出 |
| 淘汰不开心 | 哑光黑碎片 | 抓起，扬手抛向海里，碎片下沉熄灭 |
| 情话 / 一刹那 | 烟花 | 从海面升起，炸成粉金色圆环，随即熄灭 |
| 时差 | 两只指针错开 90° 的钟 + 不同步的潮水线 | 她脚边已湿，他脚边还是干的 |
| 收集回忆 | 玻璃罐 | 一颗颗放进罐里，罐内光量递增 |
| 失去 | 罐内光逐格熄灭 | 手收回，掌心朝下压住颤抖 |

写法要求：每行必须有一个**动词**。「时差」如果只写「错开的钟」，是静物；写上「她脚边已湿，他脚边还是干的」，才是可拍的镜头。

## 十、情绪曲线

用**动词短语链**写，不要用「先抑后扬」这种批评术语。

范本：

> 渺小、挫败 → 被照亮 → 温热日常 → 烟花式的盛放与骤然熄灭 → 时差错位、克制的告别

每条曲线的末端必须有「克制」或「收」这个动作。MV 的通病是结尾用力过猛，而结尾恰恰应该是全片最轻的地方。

情绪曲线要能直接翻译成运镜幅度：

> 镜头运动幅度与歌词情绪正相关：前 8 秒最静，22–36 秒最满，37 秒后重新收。

这样曲线就不是文学描述，而是可执行的运动参数。

### 节奏来自差异

如果每一镜都用最大对比强调一切，高潮就不突出。

**必须给过渡段保留低对比。** 具体做法：

- 全片只有 1–2 镜允许「最亮档」占 15%（其余镜头压到 8% 以下）
- 只有情绪峰值那一镜允许高光溢出
- 平淡段落的饱和度要真的降下来，不要「都挺好看」

观众感觉不到「高潮」，通常不是因为高潮不够强，而是因为前面的段落也太强了。

## 十一、画风锚定串

一句可复制、全片零改动的风格字符串，包含五层信息：

```
二维手绘动画电影质感 + 2.5D 景深
赛璐璐上色、双色阴影（暖阴影 + 冷补光）
2px 不均匀描边
轻微纸张颗粒与 1–2px 胶片抖动
柔和体积光、空气感光晕
```

再加三条约束：

```
写实向动画比例，成人头身比约 6.5
表情克制，不做 Q 版夸张
模拟 35mm 电影镜头质感，f/4 浅景深
```

**这串字符在每一镜的提示词里原样出现，一个字都不改。** 改写同义句 = 每镜重新定义一次风格 = 十几镜后画风必然漂走。

如果用户换项目（换画风），只换这一串，其余方法论照用。

## 十二、视觉设计自检

- [ ] 每一镜都有一句动词短语写的「镜头目的」
- [ ] 每一镜都压成三档明度检查过焦点，最亮档只给一个东西
- [ ] 三色角色已分配，主体色全片不变
- [ ] 强调色一镜最多出现一次，面积 ≤ 10%
- [ ] 色板每段有 HEX + 明度关系 + 颜色角色 + 画幅占比
- [ ] 冷暖和冷暖之间的转换有空间依据和桥接镜头
- [ ] 最后一段留了余温，没有冷到底
- [ ] 角色通过了「两底三状态」可读性测试
- [ ] 过渡段保留了低对比，没有每镜都拉满
- [ ] 风格锚逐字复制，全片零改动
