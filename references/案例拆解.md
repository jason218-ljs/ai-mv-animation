# 案例拆解：《把回忆拼好给你》MV 动画

这是本 skill 的黄金范本。原文附在文末，建议先读拆解，再对着原文看每一节为什么这么写。

---

## 项目概况

| 项 | 值 |
|---|---|
| 歌曲 | 《把回忆拼好给你》 |
| 段落 | 0:21–1:08（歌曲时间） |
| 成片 | 47 秒 |
| 歌词 | 15 句（原文标注 14 句，实为笔误，见下） |
| 镜头 | 15 个（一句一镜，无拆镜） |
| 画风 | 二维手绘赛璐璐 + 2.5D 景深 |
| 分辨率 / 帧率 | 1920×1080 / 24 fps |

> **关于「14 句」**：原文第一节写「共 14 句歌词，切为 15 个镜头」，但第六节实际列出了 15 条互不重复的歌词，从「我们都是渺小真实存在」到「爱炙热的你 却忘了爱自己」。所以真实情况是 15 句对 15 镜，一句一镜，没有拆镜。
>
> 这个笔误正好说明了为什么需要脚本：手工排表时「句数」和「镜数」很容易对不上，而对不上的直接后果就是少排一镜或错拆一镜。用 `scripts/build_shotlist.py` 生成骨架，表头会把两者分列显示。

## 九节结构，每节解决一个问题

原文的九个小节不是随便分的，每一节对应一个「如果不写就会出事」的环节。

### 一、任务定义 → 解决「时间码混乱」

关键动作：

1. **区分两套时间**：「以提供的人声音频与逐句时间轴为准，歌词出现时刻只用于对齐，不作为画面时间码；画面时间一律从 0:00 起算」。
2. **锁定镜头数**：「共 14 句歌词，切为 15 个镜头，逐句一镜，不做句内切」。

这两句是全篇的地基。第一句防止后期改前奏导致全片重排，第二句防止生成时临时加镜。

### 二、技术方向 → 解决「画风漂移」

七个具体参数：动画形态、比例、镜头语言配额、运动规律、生成方式、音频处理。

最值得学的是**配额制**：「全片只允许 2 次快速运镜（S08 甩镜、S11 极慢镜头反差）」。它把「克制」变成了可执行的数字，而不是形容词。

其次是**「人慢景快」**：人物 12 张/秒（on twos），水/云/烟花 24 帧满帧。这是手绘质感的来源，也是普通 AI 视频最缺的一层。

### 三、视觉风格、色调与情绪基调 → 解决「色调漂移」

四层结构：

1. **世界观**（一句话，含一条异常规则）
2. **情绪曲线**（动词短语链）
3. **色板走向**（五段，每段带时间码 + HEX + 饱和度 + 画幅占比）
4. **光线方向**（方位恒定 + 色温分段）

第三层是硬约束，第四层是防穿帮。注意最后一段的「余温」处理：「回到冷蓝，但画面边缘始终保留一缕琥珀余温，不许彻底变灰」——这一句决定了片子的回味。

### 四、主视觉元素与角色设定 → 解决「人物变脸」

三段：核心道具（状态机）、主角 A、主角 B、标志性意象（映射表）。

道具状态机写得极细：`0:00 空罐、0:13 约三成、0:22 过半、0:25 满罐、0:41 逐格熄灭、0:47 空罐但罐壁残留余光`，并加一句「状态必须逐镜递增，不可跳变」。

角色写得极细：发卡在右侧、袖口长过手背、红绳在左脚踝、琥珀线在右手腕。**每一个细节都是后期校验点。**

### 五、输出参数 → 解决「交付返工」

一张七行表：画幅、分辨率、帧率、时长、色彩、交付、分层。

两个细节值得抄：

- 「若模型仅支持 25/30 fps，生成后变速回 23.976」——预判了模型限制并给了补救方案
- 「不加 LUT 滤镜，色调由本提示词色板控制」——因为 LUT 会放大分段色差

### 六、逐句分镜 → 解决「执行」

15 个镜头，每个固定五要素：**画面 / 运镜 / 转场 / 卡点**（部分镜有额外说明）。

注意每个转场都是画面内的物理事件：云层擦过、碎片落水轨迹、光斑扩张、光斑扫过、水花扑镜、雨滴放大、穿玻璃、圆形空洞、动作接动作、点接点、瞳孔扩张、粒子消散、潮水漫过、暗接暗。**没有一个叠化。**

### 七、节奏与卡点规则 → 解决「唱起来不顺」

三条规则 + 一条总控：

1. 起幅 = 句首人声起音
2. 尾字落位时画面最稳（**并附了完整的 15 个尾字清单**）
3. 只允许「烟花」「一刹那」「时差」三处内部加速
4. 运动幅度与情绪正相关（前 8 秒最静，22–36 秒最满，37 秒后收）

第二条附清单这个动作是关键——它把一条抽象规则变成了可逐项核对的工作表。

### 八、连贯性约束 → 解决「拼不起来」

七类：角色、场景、道具、光线、轴线、跨镜衔接、风格锁定。

每条都可核验：「红绳位置」「同一处磕碰缺口」「S13 必须回到 S01 的同一机位轴线」「少女始终在画面左、少年在右」。

### 九、负面提示 → 解决「画面脏东西」

九类，覆盖文字、人物、时代感、质感、角色变形、解剖、运镜、叙事逻辑、画幅。

其中「不要提前出现烟花或提前熄灭罐中光」这类**叙事逻辑负面项**很少见但很重要——模型不懂剧情，它会在任何一帧里放它觉得好看的东西。

## 用新方法论回看这个案例

后来补进来的几套理论，正好能解释原案例为什么这么做——说明作者是凭经验摸到了工业方法，只是没写出来。

| 原案例的做法 | 对应的理论 |
|---|---|
| 少女「眼神安静、少表情」 | **库里肖夫效应**：中性表情留白给剪辑。接大海是辽阔，接空罐是失落 |
| S01 人影只占画幅 1/12 | **明度与比例**：远景靠大色块和剪影认人，不靠配饰 |
| 「米白色 oversized 粗针毛衣」 | **远景识别码**：大色块是远距离唯一可读的特征 |
| 色板五段带 HEX 与画幅占比 | **色彩脚本**：把情绪画成一条可读的色彩线 |
| 0:37 后「保留一缕琥珀余温」 | **对比度预算**：结尾不能归零，否则情绪白给 |
| S07 暖色从袖口抹出的缝隙进入 | **冷暖桥接**：温度变化必须有空间依据、发生在动作里 |
| 罐身「同一处磕碰缺口」 | **瑕疵即锚点**：完美看起来假，缺陷既给质感又给一致性 |
| 人物 12 张/秒、环境 24 帧满帧 | **时间控制**：帧率就是情绪档位，「人慢景快」制造回忆感 |
| S13「她脚边已湿，他脚边还是干的」 | **意象映射**：「时差」被翻译成一个可拍的动作，不是静物 |
| S05、S13 同一侧机位、女左男右 | **轴线规则**：越轴是最贵的错误，后期无法修 |

反过来，这个案例也有三处按新方法论可以更强：

1. **没做明度分组**。色板写了 HEX 和饱和度，但没写「每镜最亮的是谁」。如果补上，S02 的黑碎片、S08 的罐中光会更抓眼。
2. **没有中性反应镜头的冗余**。全片每镜都有明确内容，没有留一个「空」的表情镜头供剪辑试接。补一个，结尾的告别会更有弹性。
3. **尾字清单是事后列的**。原文把它放在第七节（节奏规则），其实应该在分镜阶段就逐字核对，否则生成完才发现尾字处有快速运动，只能重跑。

## 可以抽走的方法论（与本案无关也成立）

1. 画面时间与歌曲时间解耦
2. 一句一镜
3. 色板分段 + HEX + 方向锁
4. 主光方位恒定
5. 核心道具状态机
6. 转场由画面内物理媒介承担
7. 尾帧接首帧 + 同参考图 + 同种子
8. 角色设定写成可核验锚点
9. 运镜配额制
10. 人物 on twos / 环境满帧
11. 尾字清单前置到分镜阶段
12. 情绪曲线翻译成运动幅度曲线
13. 负面提示按类组织，文字标识类每镜必带
14. 收尾留余温与余白

《把回忆拼好给你》MV 动画生成提示词（0:21–1:08 / 成片 00:47）

**一、任务定义**

为歌曲《把回忆拼好给你》的 0:21–1:08 段落制作一支 47 秒的动画 MV 片段。以提供的人声音频与逐句时间轴为准，歌词出现时刻只用于对齐，不作为画面时间码；画面时间一律从 0:00 起算。共 14 句歌词，切为 15 个镜头，逐句一镜，不做句内切。

**二、技术方向**

动画形态：二维手绘动画电影质感 + 2.5D 景深。赛璐璐上色、双色阴影（暖阴影 + 冷补光）、2px 不均匀描边，轻微纸张颗粒与 1–2px 胶片抖动，柔和体积光、空气感光晕。

比例与角色：写实向动画比例，成人头身比约 6.5，表情克制、不做 Q 版夸张。

镜头语言：以缓推、缓摇、横移跟拍为主，全片只允许 2 次快速运镜（S08 甩镜、S11 极慢镜头反差）。手持呼吸感不超过 2px，禁止炫技式环绕与急推。

运动规律：人物动作按 12 张/秒的动画节奏，非写实运动模糊；水、云、烟花的动态可 24 帧满帧，形成"人慢景快"的呼吸对比。

生成方式：单次生成按镜头拆分，每段 3–4 秒独立出片，每段首帧复用上一段尾帧或指定参考帧；全程使用同一角色参考图（三视图 + 表情表）、同一场景概念图、同一随机种子，保证跨段一致性。

音频处理：模型只输出画面，不生成音轨；后期套用已对齐音频，因此所有切点必须精确落在句首人声起音上。

**三、视觉风格、色调与情绪基调**

世界观：一座退潮后的海边小城。湿沙如镜，天空低垂得像一只倒扣的玻璃罐，沙滩上散落着会发光的玻璃碎片——每一片都是一段回忆。主角收集碎片装进玻璃罐；少年是唯一能让碎片亮起来的人。

情绪曲线：渺小、挫败，到被照亮，再到温热日常，到烟花式的盛放与骤然熄灭，最后到时差错位、克制的告别。

色板走向（必须遵守，不许反向）：

- 0:00–0:08：冷灰蓝 #2E3B4E、#4A5A70，低饱和，天空占画幅 70%。
- 0:09–0:12：青蓝 #3E7C8C + 第一束琥珀 #E8A44C。
- 0:13–0:24：暖青绿 #6FA79B + 琥珀，饱和度整体上升，颗粒减少。
- 0:25–0:36：夜，品红 #D94F7A + 金 #F2C14E，高光允许轻微溢出。
- 0:37–0:47：回到冷蓝，但画面边缘始终保留一缕琥珀余温，不许彻底变灰。

光线方向恒定：主光永远来自画面右后上方；前 24 秒为冷光，25 秒起换为暖光，37 秒后重新转冷。禁止光源跳位。

**四、主视觉元素与角色设定**

核心道具｜玻璃罐：广口、厚底、带一枚磨砂木塞的老式玻璃罐。罐内光量随剧情变化：0:00 空罐、0:13 约三成、0:22 过半、0:25 满罐、0:41 逐格熄灭、0:47 空罐但罐壁残留余光。状态必须逐镜递增，不可跳变。

主角 A（"我"）：17 岁少女，黑色齐耳短发，右侧别一枚白贝壳发卡，米白色 oversized 粗针毛衣（袖口长过手背），深藏青及膝裙，赤脚，左脚踝系一圈红绳。眼神安静、少表情。

主角 B（"你"）：同岁少年，深灰蓝连帽卫衣（帽子常搭在背后），赤脚，右手腕缠一圈琥珀色细线。他走过的地方，沙子会短暂发亮。台词不出现口型特写以外的表演。

标志性意象：大海对应"广袤"，黑碎片沉入海中对应"淘汰不开心"，烟花对应"情话/一刹那"，两只指针错开的钟与不同步的潮水线对应"时差"。

**五、输出参数**

| 项目 | 设定 |
|---|---|
| 画幅比例 | 16:9（横屏） |
| 分辨率 | 1920×1080 |
| 帧率 | 24 fps 原生；若模型仅支持 25/30 fps，生成后变速回 23.976 |
| 时长 | 00:00:47（47 秒整，误差不超过 ±2 帧） |
| 色彩 | Rec.709，SDR，不加 LUT 滤镜，色调由本提示词色板控制 |
| 交付 | 无水印、无边框、无片头片尾、无音轨；建议 ProRes 422 或高码率 H.264 |
| 分层 | 角色层 / 背景层 / 光效层 分开输出，便于后期卡点 |

**六、逐句分镜（时间均为成片时间）**

S01｜0:00–0:03｜我们都是渺小真实存在
画面：大远景俯拍。镜面湿沙，两个极小的人影一前一后立在浅滩，人影高度只占画幅 1/12；画面上方三分之二是厚重灰蓝云层，云里悬着一只巨大倒扣玻璃罐的轮廓。
运镜：垂直下降 + 极缓推近，每 3 秒下移约 8% 画幅，近乎静止的漂浮感。
转场：云层下缘横扫过镜头（柔和擦除）进入下一镜。
卡点：第一句人声起音瞬间，人物脚下水面震开一圈涟漪。

S02｜0:03–0:06｜祈愿小世界里不只有挫败
画面：中景。少女蹲在浅滩，双手捧起湿沙，沙里混着几片哑光黑碎片；她低头，睫毛压得很低；背景远处一艘剥落的搁浅木船。
运镜：横向平移，半身跟拍，机位齐胸口，轻微呼吸感抖动。
转场：她合掌，黑碎片从指缝落下，用落下的轨迹做动作匹配接下一镜。

S03｜0:06–0:09｜直到遇见你我以为就光明起来
画面：特写。碎片落水的一瞬，水面倒影里出现少年 B 的逆光剪影；镜头随倒影上摇，浅滩尽头少年正走来。第一束琥珀光从右后上方穿云而下，只打亮他的肩线。
运镜：由俯拍特写向上摇 + 焦点从水面拉到远景人物。
转场：光斑急速扩张，全屏白化 1–2 帧。

S04｜0:09–0:13｜眼睛里看到的都是广袤无垠的大海
画面：少女主观视角。她抬眼，云裂开，海平线露出，海面被斜光切成千万片碎金；她的睫毛作为前景虚化压住画幅下缘。
运镜：极缓推 + 轻微上升，海平线稳定在画幅 40% 高度。
转场：穿过睫毛产生的光斑垂直扫过画面（光斑擦除）。

S05｜0:13–0:16｜有你在的日子不可能被取代
画面：双人中景。两人并肩走在浅滩，少年走外侧（靠海），两条拉长的影子交叠成一条；少女低头看影子，嘴角出现极小的弧度。
运镜：侧向平移跟拍，与人物同速，机位压到膝盖高度，让影子成为主体。
转场：脚下溅起的水花扑向镜头（脏遮罩擦拭）。

S06｜0:16–0:19｜在最灰暗的日子你陪着我发呆
画面：内景。只有一扇窗的小房间，窗外灰雨。少女抱膝坐在窗台，少年靠墙坐在她旁边地板上，两人都不说话，中间放着一只空玻璃罐。室内只有窗外一点冷光。
运镜：固定机位 + 极缓推，三分法构图，人物偏左下，右侧大面积暗部。
转场：雨滴沿玻璃滑下，其中一颗放大充满画面（水体转场）。

S07｜0:19–0:22｜你让我学会如何拨开阴霾
画面：少女抬手，用袖口在起雾的窗玻璃上抹出一道弧；玻璃外的灰云被这道弧"擦开"，露出一条金色海平线的缝。
运镜：手部特写跟随手部横移，抹出的路径始终保持在画面中央。
转场：镜头沿被抹开的通道向前穿过玻璃（穿幕转场）。

S08｜0:22–0:25｜将快乐全都收集将不开心全都淘汰
画面：两个动作段落各约 1.5 秒——先把暖光碎片一颗颗放进玻璃罐（罐内光量过半），随后一把抓起哑光黑碎片扬手抛向海里，黑碎片下沉熄灭。
运镜：前段绕玻璃罐 orbit 约 60°；后段切手部特写甩镜跟抛出的动作。
转场：黑碎片在空中拼成一个圆形空洞，镜头从洞中穿出（图形遮罩）。

S09｜0:25–0:28｜你对我说的情话
画面：夜。少年坐在浅滩木桩上侧头对少女说话，只见口型与气息；前景是罐中漂浮的光。他手腕的琥珀细线随说话轻微发亮。
运镜：过肩镜头，越过少女肩头拍他，再缓移到能同时看见两张侧脸。

**七、节奏与卡点规则**

全片 15 个镜头对应 14 句歌词，每个镜头起幅 = 该句人声起音，句内一律不切。

句中尾字（"在/败/来/海/代/呆/霾/汰/话/花/那/拔/差/下/己"）落位时，画面须处于构图最稳的瞬间，避免在尾字上做快速运动。

允许镜头内部加速的仅有三个词："烟花""一刹那""时差"。

整体为抒情中速，镜头运动幅度与歌词情绪正相关：前 8 秒最静，22–36 秒最满，37 秒后重新收。

**八、连贯性约束**

角色一致性：三视图 + 表情表绑定；发型、发卡、毛衣针脚、红绳位置、琥珀线缠绕圈数、赤脚，全片不得改动或增减配饰。

场景一致性：同一段海岸线、同一排防风桩、同一艘搁浅木船；小房间的窗框位置、窗台高度、墙角线固定。S13 必须回到 S01 的同一机位轴线。

道具连续性：玻璃罐的型号不变、罐内光量只按设定递增/递减，不得闪回或跳变；罐身始终有同一处磕碰缺口。

光线一致性：主光恒定在右后上方；36 秒前的影子方向与 37 秒后的影子方向不翻转。

轴线规则：S05、S13 保持同一侧机位，少女始终在画面左、少年在右；不越轴。

跨镜衔接：每段生成时以上一段尾帧为首帧参考，转场处允许 2 帧重叠，但人物姿态必须能接上。

风格锁定：全片只用一种画风（二维手绘赛璐璐），不得在中途漂移成三维、写实、水彩或像素。

**九、负面提示（负面提示词）**

不要出现：片名、贴纸、水印、Logo、台标、边框、日期时间码；不要出现真实人物肖像或歌手形象；不要出现除两位主角外的第三个人物、人群、动物（背景远景亦不可）；不要出现现代城市高楼、汽车、手机、霓虹广告牌；不要写实照片质感、三维渲染感、CG 塑料感、过度磨皮、HDR 艳色；不要人物换装、换发型、换鞋、增加配饰；不要手指畸形、多指、少指、肢体穿模、脸部崩坏、双眼不对称；不要镜头剧烈晃动、快速变焦、无意义旋转、越轴跳切；不要人物直视镜头或对镜头说话；不要突然的白天/夜晚切换、天气乱变；不要提前出现烟花或提前熄灭罐中光；不要在歌词尾字处硬切；不要画面上下黑边（信箱）或拉伸变形。
