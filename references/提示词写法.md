# 提示词写法

生成提示词不是「描述一幅画面」，是**给一个没有记忆的模型写施工图**。它只做两件事：把这一帧画出来，并且画得像上一帧。

---

## 一、单镜提示词五段式

固定顺序，固定标签，不要自由发挥。

```
【画面】主体 + 动作 + 环境 + 光位 + 情绪
【运镜】类型 + 幅度（数字）+ 机位高度 + 焦点
【风格锚】画风 + 上色 + 阴影 + 描边 + 颗粒 + 抖动
【衔接】首帧来源 + 本镜尾帧状态
【禁止】本镜特有的负面项
```

### 【画面】

一句到底，**不写「然后」**。写「然后」说明这一镜里有两个动作，应该拆镜（但抒情歌不许拆，所以要么删一个，要么改成一个连续动作）。

顺序：谁 → 在哪 → 做什么（**含起势**）→ 做什么之后还留着什么（**含跟随**）→ 明度焦点在哪 → 光从哪来 → 什么情绪。

范本：

> 少女蹲在浅滩，肩膀先微微一沉才伸手捧起湿沙，沙里混着几片哑光黑碎片；她低头，睫毛压得很低；最亮的是她指缝间漏下的那点沙粒；背景远处一艘剥落的搁浅木船。

四个分句，用分号隔开，各管一层（主体动作+起势 / 微表情 / 明度焦点 / 背景）。分号让模型知道这是四层信息，而不是四个连续动作。

**两条必须补的**：

- **起势**：「肩膀先微微一沉才伸手」——AI 默认从静止突然启动，不写就没有重量
- **明度焦点**：「最亮的是指缝间的沙粒」——不写，模型会让全画面都亮，焦点散掉

**跟随动作**如果这一镜有动作，还要写一句「她停下之后，袖口和短发还向前荡了一下才落回」。这条决定人物是「活着」还是「是模型」。

### 【运镜】

**镜头运动放在这一段的最前面，并且单独成句。** 埋在长句中间大概率不生效。

必须给数字。没有数字的运镜描述，模型会自己决定幅度，而它的默认值通常比你要的大。

四件事要写全：**运动类型 + 幅度（数字）+ 机位高度与角度 + 起幅落幅景别**。

范本：

> 横向平移，半身跟拍，机位齐胸口，轻微呼吸感抖动。

或：

> 从全景极缓推至近景，每 3 秒下移约 8% 画幅，机位在人物胸口高度，近乎静止的漂浮感。

**起幅落幅一定要写**（「从全景到近景」）。只写「推近」，模型不知道从哪推到哪，中间容易变形或跳跃。

**主体运动与镜头运动必须分开**。不要写「镜头推向奔跑的人」，要写「镜头缓慢推近。一个男人从画面左侧跑向右侧。」——混写会让模型把两个动词融合成奇怪的运动。

运镜词的精确选择（dolly vs zoom、pan 的歧义、orbit 的角度上限）见 `references/生成工具实战.md`。

### 【风格锚】

**逐字复制，全片零改动。** 这是整份文档最重要的一条规则。

```
二维手绘动画电影质感 + 2.5D 景深；赛璐璐上色、双色阴影（暖阴影 + 冷补光）；2px 不均匀描边；轻微纸张颗粒与 1–2px 胶片抖动；柔和体积光、空气感光晕；写实向动画比例，成人头身比约 6.5；表情克制，不做 Q 版夸张；模拟 35mm 电影镜头质感，f/4 浅景深。
```

为什么必须逐字复制：模型对「风格」的理解是每次重新计算的。你写「手绘感赛璐璐」，它这次理解成 A，下次理解成 B。同一串字符反复出现，等于给它一个固定坐标。改写同义句，坐标就漂了，十几镜之后画风会肉眼可见地滑走。

**风格锚里要有具体型号，不要写「电影感」。** 「电影感」是最空的词，模型无法锚定；「35mm 焦段，f/4 光圈」这类具体字符串在训练数据里和真实影像强绑定。

**主体描述同样逐字复制。** 第一镜写「米白色 oversized 粗针毛衣」，第二镜就不能改成「宽松白毛衣」——换近义词等于重新定义主体。

**别忘了瑕疵。** 完美看起来假。风格锚后面补一句「毛衣起球、袖口磨白；玻璃罐身右下有一处磕碰缺口」。这既是质感来源，也是最强的跨镜一致性锚点。

### 【衔接】

明确写首帧从哪来、尾帧要停成什么样。这一句是给「图生视频」和「下一镜」两方看的。

范本：

> 首帧使用 S06 尾帧；尾帧停在袖口抹到画面右缘、金色海平线的缝刚露出的瞬间。

### 【禁止】

只写本镜特有的负面项。通用负面项走负面库，不要每镜重复粘贴（浪费 token，且会稀释重点）。

本镜特有负面项举例：

- 本镜有手部特写 → `不要手指畸形、多指、少指`
- 本镜有水面倒影 → `不要倒影与实体不同步`
- 本镜有烟花 → `不要烟花提前出现在画面边缘`

## 二、参考图提示词写法

### 角色三视图 + 表情表

一张图里同时给出：正面 / 侧面 / 背面全身，加 4–6 个表情头。

写法要点：

1. **先写身份与年龄，再写外形，最后写服装细节**
2. **配饰必须带位置和数量**：「右侧别一枚白贝壳发卡」「左脚踝系一圈红绳」「右手腕缠一圈琥珀色细线」
3. **服装写版型而不是颜色**：「米白色 oversized 粗针毛衣，袖口长过手背」——「袖口长过手背」是可核验的，比「宽松」有用一百倍
4. **明确要求白底、无背景、均匀布光**，否则参考图会带进环境色，污染后续所有镜头
5. **表情表写「克制向」**：安静、微怔、极小弧度、垂眼。不要「大笑、惊讶、愤怒」这种强表情，否则模型会把夸张表情带到正片

范本：

> 角色设定图，白底，均匀布光，无背景。17 岁少女，黑色齐耳短发，右侧别一枚白贝壳发卡；米白色 oversized 粗针毛衣，袖口长过手背；深藏青及膝裙；赤脚，左脚踝系一圈红绳。写实向动画比例，头身比约 6.5。左侧为正面/侧面/背面全身三视图，右侧为 6 个表情头部特写：安静、微怔、垂眼、极小的笑意、出神、抿唇。表情克制，不做 Q 版夸张。二维手绘赛璐璐上色，2px 不均匀描边，双色阴影。

### 场景概念图

写法要点：

1. **写「可复用的地标」**：同一排防风桩、同一艘搁浅木船、同一段海岸线——这些是后续每镜都要出现的锚
2. **写比例尺**：地平线在画幅多少高度、人物占比多少
3. **写介质**：湿沙如镜、天空低垂——介质决定了光和反射，是场景的物理基础
4. **不写人物**，或只写「两个极小的人影」作为比例参照

范本：

> 场景概念图，退潮后的海边浅滩，湿沙如镜面反射低垂的灰蓝天空；画幅上方三分之二是厚重灰蓝云层，云里隐约悬着一只巨大倒扣玻璃罐的轮廓；中景一排防风桩，远景一艘剥落的搁浅木船；海平线在画幅 40% 高度；两个极小的人影站在浅滩上，高度约占画幅 1/12。二维手绘赛璐璐，2px 不均匀描边，纸张颗粒，柔和体积光。

### 关键帧（每镜首帧）

关键帧提示词 = 【画面】段 + 【风格锚】段 + 角色/场景参考图。不需要写运镜和转场。

## 三、完整单镜示例

以 S07 为例（少女用袖口擦开雾气，露出金色海平线）：

```
【画面】内景，起雾的窗玻璃前，17 岁少女先把肩膀微微下沉、右臂向内收了一下，然后才抬起手臂，用米白色粗针毛衣的袖口在玻璃上沿弧线横向抹过；弧内的雾气被擦开，露出玻璃外一条金色的海平线缝隙；其余部分仍是灰云；最亮的是缝隙里透出的那一点金，只占画面不足一成；她的侧脸在画面左侧，眼神安静；主光来自画面右后上方，冷光穿过缝隙在她睫毛上留下一点金边；她停下之后，袖口还向前荡了一下才落回。

【运镜】手部特写跟随手部横移，抹出的路径始终保持在画面中央；机位齐胸，镜头与手同速；从近景开始，随抹开的动作微微推至手部特写。

【风格锚】二维手绘动画电影质感 + 2.5D 景深；赛璐璐上色、双色阴影（暖阴影 + 冷补光）；2px 不均匀描边；轻微纸张颗粒与 1–2px 胶片抖动；柔和体积光、空气感光晕；写实向动画比例，成人头身比约 6.5；表情克制，不做 Q 版夸张；模拟 35mm 电影镜头质感，f/4 浅景深。毛衣起球、袖口磨白。

【衔接】首帧使用 S06 尾帧（雨滴放大成失焦水膜的瞬间）；尾帧停在袖口抹到画面右缘、金色缝隙刚完全露出的瞬间，供 S08 穿幕使用。

【禁止】不要手指畸形、多指、少指；不要让袖口变成短袖；不要在缝隙里出现第二个人；不要出现字幕或水印；不要画面上下黑边。
```

对照看这一版比「正确但干」的版本多了什么：

| 加的东西 | 在哪 | 作用 |
|---|---|---|
| 「肩膀先下沉、手臂向内收」 | 画面 | 起势，动作有重量 |
| 「沿弧线横向抹过」 | 画面 | 弧线，不是机械臂 |
| 「最亮的是缝隙那点金，不足一成」 | 画面 | 明度焦点，观众知道看哪 |
| 「袖口还向前荡了一下才落回」 | 画面 | 跟随，有空气感 |
| 「从近景推至手部特写」 | 运镜 | 起幅落幅，防中间变形 |
| 「模拟 35mm，f/4」 | 风格锚 | 具体镜头，不是「电影感」 |
| 「毛衣起球、袖口磨白」 | 风格锚 | 瑕疵，质感 + 一致性锚 |

## 四、负面提示的组织方式

不要把所有负面词平铺成一长串，按**类别**组织，每类只在相关镜头里出现。完整词库见 `assets/负面提示词库.md`。

**用之前先确认平台支不支持负面字段。** Runway Gen-4 不支持，写了反而反噬；Veo 只吃名词短语；Kling 有违禁词过滤。详见 `references/生成工具实战.md`。

十类：

1. **文字标识类** — 片名、贴纸、水印、Logo、台标、边框、日期时间码（**每镜必带**）
2. **人物类** — 真实人物肖像、歌手形象、第三个人、人群、动物（连背景远景也不可）
3. **时代感类** — 现代城市高楼、汽车、手机、霓虹广告牌
4. **质感类** — 写实照片质感、三维渲染感、CG 塑料感、过度磨皮、HDR 艳色
5. **角色变形类** — 换装、换发型、换鞋、增加配饰
6. **解剖类** — 手指畸形、多指、少指、肢体穿模、脸部崩坏、双眼不对称
7. **运镜类** — 需要固定机位时禁 camera shake / motion blur；需要甩镜时禁 distorted face / warped edges
8. **动作质感类** — 无预备直接启动、到终点硬停、走直线、匀速、人物如蜡像
9. **叙事逻辑类** — 人物直视镜头或对镜头说话、突然的昼夜切换、天气乱变、提前出现烟花、提前熄灭罐中光、在歌词尾字处硬切
10. **画幅类** — 上下黑边（信箱）、拉伸变形

**第 1 类和第 10 类是每镜必带**，其余按镜内容挑选。

## 五、提示词自检十问

写完每一镜，按顺序问：

1. 【画面】里有没有「然后」？有就说明两个动作挤在一镜里。
2. 【画面】有没有起势？动作是不是从静止突然启动的？
3. 【画面】有没有跟随？停下来之后还有东西在动吗？
4. 【画面】有没有写明度焦点？最亮的地方只有一个吗？
5. 【运镜】里有没有数字？没有就是失控。
6. 【运镜】有没有写在句首、单独成句？埋在长句中间不生效。
7. 【运镜】有没有写起幅和落幅景别？没写，中间容易变形。
8. 【风格锚】和上一镜是不是一字不差？不是就在漂。
9. 【衔接】有没有写清尾帧停成什么样？没写，下一镜的首帧就靠猜。
10. 【禁止】有没有带上文字标识类？平台支持负面字段吗？
