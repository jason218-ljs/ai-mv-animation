# AI 动画 MV 导演 · ai-mv-animation

> 把一首歌的某段歌词，做成一支能逐段生成、跨镜拼得起来的 AI 动画 MV。
> 一套面向 AI 视频生成的**方法论 + 模板库 + 校验脚本**，以 Agent Skill 形式组织。

---

## 这个 Skill 解决什么问题

用 AI 做 MV，真正的难点从来不是「画面好不好看」，而是两件事：

1. **跨镜一致性** —— 模型每次生成都是独立事件，没有上一镜的记忆。15 个 3–4 秒的片段拼起来，很容易像 15 支不同的片子。
2. **卡点精度** —— 画面时间如果跟着歌词时间轴走，前奏一改长度，全片时间码集体崩盘。

本 Skill 的全部规则都围绕一个目标：**让 15 个彼此独立的片段，拼起来像一个人拍的。**

| 类型 | 内容 |

## 十条铁律（摘录）

1. **画面时间从 0:00 起算**，与歌曲时间轴解耦
2. **一句一镜，句内不切**
3. **明度先行**，色板带时间码与方向锁
4. **主光方位全片恒定**，只允许色温变
5. **核心道具写成状态机**，并给它一处永久瑕疵
6. **转场从画面内容里长出来**，禁用外挂转场特效
7. **每段生成以上一段尾帧为首帧**，参考图与种子全程不变
8. **风格锚与主体描述逐字复制**，不换近义词
9. **动作必须有起势和收势**
10. **情绪不在表演里，在剪辑里**

完整版见 [`SKILL.md`](./SKILL.md)。

## 六阶段工作流

```
阶段 0  需求锚定        8 项要素，缺哪项补哪项，不要自己编
阶段 1  色彩脚本与总纲   先写镜头目的 → 再压明度 → 再分配颜色角色 → 最后填 HEX
阶段 2  角色与场景设定   三视图 + 表情表；「两底三状态」可读性测试
阶段 3  分镜表          脚本生成骨架 → 逐镜填六要素 → 过 6 项检查点
阶段 4  逐段生成        先预演再生成；严格串行；只重跑失败的那一镜
阶段 5  一致性与卡点校验  七类约束、三类卡点规则逐项过
阶段 6  交付与合成      帧率统一、手绘感、色彩、音轨、分层
```

## 安装

这是一个遵循 `SKILL.md` + YAML frontmatter 约定的 Agent Skill，可直接用于支持该约定的 Agent 环境。

**用户级安装**（对所有项目生效）：

```bash
git clone https://github.com/jason218-ljs/ai-mv-animation.git \
  ~/.workbuddy-ai/skills/ai-mv-animation
```

**项目级安装**（仅当前项目生效）：

```bash
git clone https://github.com/jason218-ljs/ai-mv-animation.git \
  .workbuddy-ai/skills/ai-mv-animation
```

装好后，Agent 在遇到「做音乐 MV / 歌词分镜 / 动画短片 / 逐句卡点视频」等任务时会自动加载。

## 快速开始

### 1. 生成分镜表骨架

```bash
python scripts/build_shotlist.py lyrics.txt --fps 24 -o 分镜表.md
```

`lyrics.txt` 每行一句歌词，支持四种写法：

```
0:21 | 0:24 | 我们都是渺小真实存在
0:21 | 我们都是渺小真实存在
0:21-0:24 我们都是渺小真实存在
0:21 我们都是渺小真实存在
```

- 只给起始时间时，结束时间自动取下一句的起始时间
- 最后一句必须给结束时间，或用 `--duration` 指定全片总时长
- 以 `#` 或 `//` 开头的行视为注释

### 2. 校验已写好的分镜表

```bash
python scripts/build_shotlist.py --check 分镜表.md --fps 24
```

脚本会检查时间轴单调、无重叠、总时长对得上，并标出偏离 3–4 秒舒适区的镜头。

### 3. 按阶段 1–6 推进

从 `assets/项目总纲模板.md` 开始填，顺序不要颠倒。

## 适用范围

**适用**：有歌词的音乐 MV、动画短片、逐句卡点视频、需要跨镜一致性的分段生成项目。

**不适用**：纯实拍剪辑、无歌词的纯音乐可视化、单张图生成。
