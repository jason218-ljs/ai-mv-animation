# 场景设定卡模板

> 一个场景一张。场景卡的作用不是「好看」，是给出**跨镜可复用的地标**——让 15 个镜头看起来发生在同一个地方。

---

## 场景：【外景·退潮浅滩 / 内景·小房间 / ……】

### 基础

| 项 | 内容 |
|---|---|
| 时间 | 【黄昏 / 夜 / 无明确时间（避免昼夜切换）】 |
| 天气 | 【阴、云层厚重 / 灰雨 / 无风】 |
| 空间类型 | 【外景 / 内景】 |
| 镜头中的出现 | 【S01、S02、S03…】 |

### 可复用地标（每个镜头都要出现的锚）

| # | 地标 | 位置 | 数量 | 校验方式 |
|---|---|---|---|---|
| 1 | 【一段海岸线】 | 【贯穿画面中景】 | — | 【地平线高度固定】 |
| 2 | 【一排防风桩】 | 【中景右侧】 | **【N】根** | **数：桩子根数** |
| 3 | 【一艘剥落的搁浅木船】 | 【远景偏左】 | 【1 艘】 | 【船体倾斜方向】 |
| 4 | 【】 | 【】 | 【】 | 【】 |

> 数量类地标（桩子、船、窗）必须写数字。模型每镜会自己决定「几根桩」，不写就会变。

### 物理介质

介质决定光怎么走，是场景的物理基础，不是装饰。

| 介质 | 描述 | 光学后果 |
|---|---|---|
| 【湿沙】 | 【如镜，含水膜】 | 【完整倒影，人物在沙上有倒影】 |
| 【云层】 | 【低垂，厚重】 | 【漫射为主，光需穿缝而下】 |
| 【雾 / 雨 / 尘】 | 【】 | 【体积光可见，光斑扩散】 |

### 内景固定元素（仅内景填）

| 元素 | 位置 | 校验方式 |
|---|---|---|
| 窗框 | 【画面右侧三分之一处】 | 【每镜窗框位置不变】 |
| 窗台高度 | 【离地约 90cm，齐坐姿胸口】 | 【人物坐姿时窗台在胸口】 |
| 墙角线 | 【画面左下角可见】 | 【】 |
| 唯一光源 | 【窗外，冷光】 | 【室内无第二光源】 |

### 构图约束

| 项 | 值 |
|---|---|
| 地平线高度 | 【画幅 40%】 |
| 天空占比 | 【70%（前段）】 |
| 人物占比 | 【大远景时 1/12 画幅】 |
| 轴线 | 【少女始终在画面左，少年在右】 |

---

## 参考图生成提示词

```
场景概念图，{时间}，{地点与状态}，{物理介质}；{画幅上方占比}为{天空/云层描述}，{云层里的特殊元素}；中景{地标 1}，远景{地标 2}；海平线在画幅 {N}% 高度；{人物比例参照，如：两个极小的人影站在浅滩上，高度约占画幅 1/12}。{风格锚原样复制}。
```

---

## 场景一致性速查

```
地平线高度：【40%】
防风桩：【N 根，中景右侧】
搁浅木船：【1 艘，远景偏左，向左倾斜】
主光方位：【右后上方】
```

---

## 填卡自检

- [ ] 每个地标都有数量或位置，没有「一些」「几根」
- [ ] 地平线高度给了百分比
- [ ] 写了物理介质（湿沙 / 雾 / 雨），并说明光学后果
- [ ] 内景的窗框、窗台、墙角线位置固定
- [ ] 轴线方向已定（谁左谁右）
