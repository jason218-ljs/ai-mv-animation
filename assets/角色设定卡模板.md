# 角色设定卡模板

> 每个主角一张。填完之后，这张卡里的每个数字都是后续所有镜头的「照抄源」——不许在分镜里临时改写，也不许换近义词。

---

## 角色：【A / B / 称呼】

### 基础

| 项 | 内容 |
|---|---|
| 年龄 | 【17】 |
| 性别 | 【女】 |
| 头身比 | 【约 6.5】 |
| 表演基调 | 【眼神安静、少表情；不做 Q 版夸张】 |

### 外形锚点（必须可数）

| 项 | 内容 | 校验方式 |
|---|---|---|
| 发型 | 【黑色齐耳短发】 | 【长度到耳垂，不遮眉】 |
| 发饰 | 【右侧一枚白贝壳发卡】 | **数：1 枚；在右侧** |
| 上装 | 【米白色 oversized 粗针毛衣】 | 【袖口长过手背；起球、袖口磨白】 |
| 下装 | 【深藏青及膝裙】 | 【裙长到膝】 |
| 鞋 | 【赤脚】 | 【全程无鞋】 |
| 配饰 1 | 【左脚踝一圈红绳】 | **数：1 圈；在左脚踝** |
| 配饰 2 | 【】 | **数：【N】圈；在【部位】** |

> 配饰类必须写「数量 + 部位」。只写「红绳」和「左脚踝一圈红绳」的差别，在 15 镜之后会变成「红绳跑到右脚」和「红绳变三条」。

### 远景识别码（大色块）

远景里配饰会完全消失。所以必须有一个**占画面面积大的识别特征**。

| 项 | 内容 |
|---|---|
| 大色块 | 【米白色 oversized 毛衣，占人物面积 50% 以上】 |
| 轮廓特征 | 【齐耳短发 + 及膝裙，剪影呈 A 形】 |
| 远景靠什么认 | 【米白色块 + A 形剪影】 |
| 近景靠什么认 | 【白贝壳发卡 + 左脚踝红绳】 |

**规则**：远景靠色块认人，近景靠配饰认人。两者都要有，缺一个就会有某个景别认不出人。

### 独属的物理异常（可选，仅一个）

【如：他走过的地方，沙子会短暂发亮。】

作用：给角色一个不可复制的物理特征，比任何外貌描写都更容易被观众记住，也更容易让模型在远景中区分两个人物。

### 表情表（4–6 个，克制向）

| # | 表情 | 描述 | 用途 |
|---|---|---|---|
| 1 | 安静 | 【眼皮微垂，嘴唇闭合】 | 【默认状态】 |
| 2 | 微怔 | 【瞳孔略放大，睫毛抬起】 | 【被照亮的那一刻】 |
| 3 | 垂眼 | 【视线落在下方，脖颈微低】 | 【回避、克制】 |
| 4 | 极小的笑意 | 【嘴角一侧上扬约 1mm】 | 【温热日常】 |
| 5 | 出神 | 【视线越过镜头，焦点虚】 | 【回忆】 |
| 6 | 抿唇 | 【下唇被轻压】 | 【忍住】 |

> 表情表不要写「大笑、惊讶、愤怒」。强表情会被模型放大成卡通表情，和「表情克制」的总基调冲突。

**留白提示**：其中至少 1 个表情要足够「空」（如「安静」「出神」），专门用来做**中性反应镜头**——剪辑时可以接不同内容，产生不同含义（见 `references/电影语法.md` 库里肖夫效应）。

## 参考图生成提示词

```
角色设定图，白底，均匀布光，无背景。{年龄}{性别}，{发型}，{发饰（含位置）}；{上装（含版型细节与瑕疵）}；{下装}；{鞋}，{配饰（含位置与数量）}。写实向动画比例，头身比约 {N}。左侧为正面 / 侧面 / 背面全身三视图，右侧为 {4–6} 个表情头部特写：{表情列表}。表情克制，不做 Q 版夸张。{风格锚原样复制}。
```

### 参考图检查点

- [ ] 白底、无环境色污染
- [ ] 三视图的配饰数量完全一致（最容易在三视图之间自己加减）
- [ ] 表情表里没有夸张表情
- [ ] 有一处服装瑕疵（起球 / 磨白 / 针脚不均）
- [ ] 风格锚与项目总纲一字不差

## 两底三状态测试（必做）

生成参考图后，立刻做这个测试。目的是确认「在远景和暗部里还认得出」。

**步骤**

1. 准备两个底板：**浅墙**（如米白）和 **深墙**（如深灰）
2. 把角色分别放进去，各测三种状态：**远景（全身，占画面 1/12）**、**中景（膝以上）**、**近景（胸以上）**
3. 共六格，人物大小保持一致
4. 缩到 400px 宽（手机屏幕大小）
5. 逐格检查：头部轮廓、服装色组、关键配饰、手里的道具

| 底板 | 远景 | 中景 | 近景 |
|---|---|---|---|
| 浅墙 | ☐ 能认出 | ☐ 能认出 | ☐ 能认出 |
| 深墙 | ☐ 能认出 | ☐ 能认出 | ☐ 能认出 |

**不合格的典型表现**

| 现象 | 原因 | 修法 |
|---|---|---|
| 远景认不出 | 只有配饰做识别，没有大色块 | 加大色块面积（如把毛衣做成米白） |
| 深墙里轮廓消失 | 深藏青裙与深背景糊在一起 | 给轮廓加边缘光，或调整裙色明度 |
| 中景认得出但近景不像 | 五官不够有特征 | 强化一个面部锚点（如眼型） |

## 角色一致性速查（贴在生成时手边）

```
发饰：【右侧 1 枚白贝壳发卡】
配饰 1：【左脚踝 1 圈红绳】
配饰 2：【右手腕 1 圈琥珀细线】
鞋：【赤脚】
袖口：【盖过手背，有磨白】
远景识别：【米白色块 + A 形剪影】
近景识别：【发卡 + 红绳】
```

> 这张速查表里的文字，每一镜的提示词都照抄，**一个字都不改**。改成「宽松白毛衣」就等于换了一个人。
