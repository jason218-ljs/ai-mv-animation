# 一致性检查清单

> 用法：**每生成完一镜立刻勾一遍**，任何一项不通过就当场重跑这一镜。
>
> 不要「先记下来最后一起修」——因为下一镜的首帧要用这一镜的尾帧，错一镜会污染后面所有镜。

---

## A. 逐镜检查（每镜生成后立即执行）

镜号：S___　版本：v___

### A0 可读性（最容易被跳过，但最致命）

- [ ] 这一镜的镜头目的达成了（对照色板表的「镜头目的」列）
- [ ] 压成黑白缩略图，第一眼落点就是设计的焦点
- [ ] 最亮的地方只有一处（不是脸和道具都亮）
- [ ] 强调色（如琥珀）本镜最多出现一次，面积 ≤ 10%
- [ ] 本镜的对比度没有超出该段落的预算（过渡段不许拉满）

### A1 角色

- [ ] 发饰位置与数量正确（【右侧 1 枚白贝壳发卡】）
- [ ] 配饰位置与圈数正确（【左脚踝 1 圈红绳 / 右手腕 1 圈琥珀细线】）
- [ ] 鞋的状态正确（【赤脚】）
- [ ] 服装版型正确（【袖口长过手背，有磨白】）
- [ ] 发型长度正确（【齐耳】）
- [ ] 表情幅度克制，未出现夸张表情
- [ ] 远景尺度下仍能通过大色块认出是谁
- [ ] 无多指 / 少指 / 手指畸形（有手部时）
- [ ] 双眼对称、脸部无崩坏（有面部时）

### A2 场景

- [ ] 地平线高度与场景卡一致（【40%】）
- [ ] 可复用地标数量正确（【防风桩 N 根 / 木船 1 艘】）
- [ ] 内景的窗框、窗台、墙角线位置与场景卡一致
- [ ] 无现代建筑、车辆、人群闯入

### A3 道具

- [ ] 道具型号 / 外形未变
- [ ] 罐内光量档位与状态机表当前时间点一致（本镜应为【】）
- [ ] 永久瑕疵（【罐身右下磕碰缺口】）位置未变
- [ ] 无跳变、无闪回

### A4 光线

- [ ] 主光来自【右后上方】
- [ ] 色温符合当前色板段落（本镜应为【冷 / 暖 / 夜】）
- [ ] 影子方向与上一镜一致
- [ ] 无第二个光源

### A5 风格

- [ ] 画风是【二维手绘赛璐璐】，未漂移成三维 / 写实 / 水彩
- [ ] 描边粗细与不均匀感一致
- [ ] 双色阴影（暖阴影 + 冷补光）成立
- [ ] 有纸张颗粒与轻微胶片抖动
- [ ] 风格锚在提示词里是逐字复制的
- [ ] 主体描述（服装、配饰）在提示词里是逐字复制的，没有换近义词

### A6 画面卫生

- [ ] 无字幕、水印、Logo、边框、时间码
- [ ] 无上下黑边、无拉伸变形
- [ ] 人物未直视镜头

### A7 运镜与表演

- [ ] 运镜幅度与分镜表一致（未自己加推拉）
- [ ] 运镜词在提示词句首，且单独成句
- [ ] 主体运动与镜头运动是分开写的（没有「推向奔跑的人」这种混写）
- [ ] 人物动作是 12 张/秒的顿感，未变成 24 帧写实运动
- [ ] 手持抖动 ≤ 2px（未变成晃动）
- [ ] 本镜若含快速运镜，已确认未超全片配额

### A8 动作重量（AI 最容易缺的一组）

- [ ] 主动作有**起势**（反向的预备动作），不是从静止突然启动
- [ ] 动作停下后有**跟随**（头发、袖口、裙摆、红绳晚半拍落回）
- [ ] 肢体走**弧线**，不是直线
- [ ] 有**加减速**，不是匀速
- [ ] 有**次要动作**（轻微呼吸起伏、偶尔眨眼、衣料轻晃）
- [ ] 表情没有跟着动作一起夸张

### A9 衔接

- [ ] 首帧与上一镜尾帧能接上（姿态、位置、光线连续）
- [ ] 本镜尾帧已按分镜表停成指定状态
- [ ] 尾帧已导出存盘，命名 `S___tail.png`

---

## B. 跨镜检查（全片拼完后执行）

### B1 时间轴

- [ ] 各镜时长之和 = 成片时长（误差 ≤ 2 帧）
- [ ] 每个切点都落在句首人声起音上（误差 ≤ 1 帧）
- [ ] 句内无额外切点
- [ ] 帧率统一（全部 24 fps 或全部变速到 23.976）

### B2 卡点

- [ ] 逐字核对尾字清单：每个尾字落位时，画面处于构图最稳点
- [ ] 只有约定词处有镜头内部加速
- [ ] 重拍上的动作（如烟花炸开）实际落在重拍上

### B3 连续性

- [ ] 首镜与末镜并排看，画风一致
- [ ] 全片色调走向符合色板时间轴，无反向
- [ ] 道具状态全片单调变化，无跳变
- [ ] 影子方向全片未翻转
- [ ] 轴线：少女始终在左、少年始终在右

### B4 转场

- [ ] 每个转场都是画面内的物理事件（无叠化 / 闪白 / 划像）
- [ ] 相邻镜的转场方向能对上
- [ ] 白化类转场为 1–2 帧，黑场为 4 帧
- [ ] 收尾有 0.3 秒余白
- [ ] 冷暖转换处有桥接镜头，不是硬切换色温

### B5 电影语法

- [ ] 相邻两镜机位夹角 ≥ 30°（不够就会有跳接感）
- [ ] 没有「大特写直接接大远景」（两极景别不衔接）
- [ ] 人物看向画外时，下一镜给出了他看的东西，方向一致
- [ ] 景别推进有逻辑（剥洋葱式，或刻意反向揭示）
- [ ] 全片有 1–2 个中性反应镜头，且它们足够「空」
- [ ] 中性反应镜头试接过至少两种不同内容，选了最好的那个

### B6 节奏

- [ ] 运镜幅度有起伏，不是每镜都在动
- [ ] 全片只有一个「快」的峰值，位置在情绪最高点
- [ ] 对比度有起伏，过渡段确实压下来了
- [ ] 结尾是全片最轻的地方，没有用力过猛

### B7 交付

- [ ] 色彩 Rec.709 / SDR，未加 LUT
- [ ] 无音轨（或已套对齐音频）
- [ ] 无水印、无边框、无片头片尾
- [ ] 分层已输出（角色 / 背景 / 光效）
- [ ] 编码为 ProRes 422 或高码率 H.264
- [ ] 人物镜头是否做了 on twos（可选）

## C. 三次「回头」

拼完之后，隔一段时间再看三遍：

1. **静音看一遍** —— 只看画面能不能独立成立。如果静音看不懂在讲什么，说明意象映射没做够。
2. **闭眼听一遍** —— 只听音轨和切点的关系。如果切点有一处「提前了」或「拖了」，那就是卡点没对死。
3. **放小窗看一遍** —— 缩到手机大小。如果人物在远景里认不出是谁，说明角色锚点在远景尺度上失效了（通常是因为只靠配饰做识别，没有大色块）。

第三遍最容易发现问题，也最接近观众的真实观看条件。

---

## D. 换一双眼睛

如果条件允许，找一个人只看一遍，然后问他：

1. 这是在讲什么？（测意象映射是否成立）
2. 哪一镜最好看？（测视觉重音是否落在你想落的地方）
3. 哪里觉得跳了一下？（测 30 度规则和转场衔接）

不要问「好不好看」，要问具体的问题。观众说不出技术原因，但能准确指出「哪里不舒服」。
