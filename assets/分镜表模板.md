## 分镜表

### S01｜0:00–0:03｜【歌词】

- **镜头目的**：【一句动词短语，如「让观众感到两个人有多小」——不写形容词】
- **景别**：【大远景 / 全景 / 中景 / 近景 / 特写】｜机位角度【0°/45°/90°】｜焦段【24/35/85mm】
- **画面**：【主体 + 动作（含起势与收势）+ 环境 + 明度焦点 + 光位 + 情绪，一句到底，不写「然后」】
- **运镜**：【镜头运动 + 幅度（数字）+ 机位高度 + 起幅落幅景别 + 焦点变化】
- **转场**：【画面内什么物理媒介承接下一镜】
- **卡点**：【起音瞬间画面发生什么】
- **道具档位**：【当前档位，对照状态机】
- **尾帧**：【最后一帧停成什么样】

## 每镜提示词块（生成时直接复制）

```
S0X｜0:XX–0:XX

【画面】{主体 + 动作（含起势与收势）+ 环境 + 明度焦点 + 光位 + 情绪}

【运镜】{镜头运动放句首 + 幅度数字 + 机位高度与角度 + 起幅落幅景别 + 焦点}

【风格锚】{从项目总纲原样复制，一个字不改}

【衔接】首帧使用 S0(X-1) 尾帧；尾帧停在……

【禁止】…（文字标识类必带；先确认平台是否支持负面字段）
```

> 两条硬规则：镜头运动放句首并单独成句；主体运动与镜头运动分开写。

## 填表自检

### 时间
- [ ] 时间码首尾相接，无空洞、无重叠
- [ ] 每镜时长落在 3–4 秒（偏离的已标注理由）
- [ ] 总时长 = 各镜时长之和，误差 ≤ 2 帧
- [ ] 镜头数 = 歌词句数（或已标注拆镜位置）

### 镜头目的
- [ ] 每镜都有一句动词短语写的镜头目的
- [ ] 没有用形容词代替目的（「忧伤的蓝色」不算目的）

### 画面
- [ ] 没有「然后」，每镜只有一个动作
- [ ] 每镜都写了明度焦点（最亮的是谁）
- [ ] 每镜都写了光位
- [ ] 主动作写了起势，动作后有跟随物（头发/袖口/裙摆）
- [ ] 每镜的道具档位与状态机表一致

### 景别与机位
- [ ] 每镜都标了景别和机位角度
- [ ] 相邻两镜机位夹角 ≥ 30°
- [ ] 没有两极景别直接衔接（大特写接大远景）
- [ ] 人物看向画外时，下一镜给出了他看的东西

### 运镜
- [ ] 每镜运镜都有数字幅度
- [ ] 运镜词写在提示词句首
- [ ] 快速运镜总数 ≤ 配额
- [ ] 尾字落位的那一刻，画面没有快速运动

### 转场
- [ ] 每镜都有转场，且载体在本镜画面里真实存在
- [ ] 没有使用叠化 / 闪白 / 推拉 / 划像
- [ ] 相邻两镜：上一镜的转场描述 + 下一镜的第一句画面描述，读起来是连续的

### 衔接
- [ ] 每镜都写了尾帧停成什么样
- [ ] 每镜的首帧来源都明确（上一镜尾帧 / 指定关键帧）

### 轴线
- [ ] 双人镜头里谁左谁右，全片一致
- [ ] 同一空间的多镜保持同侧机位

### 节奏
- [ ] 运镜幅度有起伏，不是每镜都在动
- [ ] 至少留了 1 个中性反应镜头（表情足够空，可试接不同内容）
