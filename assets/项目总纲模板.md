# 《【歌名】》MV 动画生成提示词（【歌曲起止】 / 成片 【总时长】）

## 一、任务定义

为歌曲《【歌名】》的【起止时间】段落制作一支【时长】秒的动画 MV 片段。以提供的人声音频与逐句时间轴为准，歌词出现时刻只用于对齐，不作为画面时间码；画面时间一律从 0:00 起算。共【N】句歌词，切为【M】个镜头，逐句一镜，不做句内切。

> 若 M ≠ N，必须在此说明哪一句被拆成两镜，以及拆点落在句中的哪个自然停顿上。

## 二、技术方向

**动画形态**：【如：二维手绘动画电影质感 + 2.5D 景深】。【上色方式，如：赛璐璐上色】、【阴影方案，如：双色阴影（暖阴影 + 冷补光）】、【描边，如：2px 不均匀描边】、【颗粒与抖动，如：轻微纸张颗粒与 1–2px 胶片抖动】、【光效，如：柔和体积光、空气感光晕】。

**比例与角色**：【写实向动画比例，成人头身比约 X】、【表情幅度约束，如：表情克制、不做 Q 版夸张】。

**镜头语言**：以【缓推 / 缓摇 / 横移跟拍】为主，全片只允许【N】次快速运镜（【具体镜号与手法】）。手持呼吸感不超过【N】px，禁止【炫技式环绕 / 急推 / 无意义旋转】。

**运动规律**：人物动作按【12】张/秒的动画节奏，非写实运动模糊；【水、云、雨、烟花】的动态可 24 帧满帧，形成"人慢景快"的呼吸对比。

**生成方式**：单次生成按镜头拆分，每段【3–4】秒独立出片，每段首帧复用上一段尾帧或指定参考帧；全程使用同一角色参考图（三视图 + 表情表）、同一场景概念图、同一随机种子，保证跨段一致性。

**音频处理**：模型只输出画面，不生成音轨；后期套用已对齐音频，因此所有切点必须精确落在句首人声起音上。

## 三、视觉风格、色调与情绪基调

**世界观**：【场景】+【一条异常规则】+【情感投射】。一句话写完，不要超过三句。

**情绪曲线**：【动词短语链，如：渺小、挫败 → 被照亮 → 温热日常 → 盛放与骤然熄灭 → 时差错位、克制的告别】。

**色板走向**（必须遵守，不许反向）：详见 `色板与光线时间轴.md`，此处只写一句总述：【如：冷灰蓝 → 青蓝+琥珀 → 暖青绿 → 夜（品红+金） → 冷蓝留余温】。

**光线方向恒定**：主光永远来自画面【右后上方】；前【N】秒为【冷】光，【N】秒起换为【暖】光，【N】秒后重新转冷。禁止光源跳位。

## 四、主视觉元素与角色设定

**核心道具｜【道具名】**：【外形描述：尺寸、材质、细节特征】。状态随剧情变化：【时间点 1 档位 1、时间点 2 档位 2、……】。状态必须逐镜【递增 / 递减】，不可跳变。

**主角 A（"【称呼】"）**：【年龄】【性别】，【发型 + 发卡位置与材质】，【服装版型与细节，如：oversized 粗针毛衣，袖口长过手背】，【下装】，【鞋/赤脚】，【配饰 + 位置 + 数量】。眼神【情绪基调】、少表情。

**主角 B（"【称呼】"）**：【年龄】【性别】，【服装】，【鞋/赤脚】，【配饰 + 位置 + 数量】。【一条独属于他的物理异常，如：他走过的地方沙子会短暂发亮】。

## 七、节奏与卡点规则

全片【M】个镜头对应【N】句歌词，每个镜头起幅 = 该句人声起音，句内一律不切。

句中尾字（【逐字列出】）落位时，画面须处于构图最稳的瞬间，避免在尾字上做快速运动。

允许镜头内部加速的仅有：【列出具体词】。

整体为【抒情中速】，镜头运动幅度与歌词情绪正相关：【前 X 秒最静，X–X 秒最满，X 秒后重新收】。

## 八、连贯性约束

**角色一致性**：三视图 + 表情表绑定；【逐项列出不可改动的细节：发型、发卡、毛衣针脚、配饰位置与圈数、赤脚】。

**场景一致性**：【可复用的地标清单】；【内景的固定元素：窗框位置、窗台高度、墙角线】。【哪一镜必须回到哪一镜的同一机位轴线】。

**道具连续性**：【道具型号不变、状态只按设定变化、不得闪回或跳变】；【一处永久的瑕疵，如：罐身始终有同一处磕碰缺口】。

**光线一致性**：主光恒定在【方位】；【时间点】前后的影子方向不翻转。

**轴线规则**：【哪些镜保持同一侧机位】，【谁始终在画面左、谁在右】；不越轴。

**跨镜衔接**：每段生成时以上一段尾帧为首帧参考，转场处允许 2 帧重叠，但人物姿态必须能接上。

**风格锁定**：全片只用一种画风（【画风名】），不得在中途漂移成【三维 / 写实 / 水彩 / 像素】。
